# DU-FLEX 开源软件第7周线下实践（韩中双语版）

설치나 별도 서버 없이 각 폴더의 `index.html`을 더블클릭하면 브라우저에서 바로 실행됩니다.  
无需安装任何软件或启动服务器，直接双击各文件夹内的 `index.html` 即可在浏览器中打开使用。
